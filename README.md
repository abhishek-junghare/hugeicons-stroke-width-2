# Hugeicons with stroke width 2 for Iconify

This package provides Hugeicons with a stroke width of 2 for Iconify. The default stroke width is 1.5. It's useful for light themes or projects that prefer a bolder icon style.

## Installation

This will install the package under the name `@iconify-json/hugeicons`, making it a drop-in replacement with no changes required to your existing code or Iconify-based tools.

```bash
npm install @iconify-json/hugeicons@npm:hugeicons-stroke-width-2
```
